# RCL5 → RCL6 Efficiency (48h Sim) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` or implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In ≤48h wall-clock, find the most efficient home-only path from hub-ready RCL5 to RCL6 and encode the winner for live (after the already-deployed first-48h `build_heavy` hub wave).

**Architecture:** Seed a mockup room at RCL5 with hub complete (30 ext, 2 towers, storage ~100k). Bench spend modes and later link variants. Primary metric: `ticks_to_rcl6` (or extrapolated ETA from progress rate if cap hits first). Hard gate: `minStorage ≥ 20000`. Early aftercare stays on live (`build_heavy` until hub); this campaign only covers **post-hub → RCL6**.

**Tech Stack:** `ops/sim/harness.ts` mockup, existing `rcl5Mode` quotas, Vitest for any new arm/switch helpers, `.sim-learn/rcl5-to-rcl6-*.json` status.

## Global Constraints

- Home-only (no remotes).
- Success: minimize ticks hub-ready → RCL6; storage floor ≥20k.
- Do not break live first-48h aftercare (`maybeArmRcl5AftercareMode` → `build_heavy` while hub incomplete).
